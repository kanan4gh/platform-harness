# 要求内容

> **これは記入例である**(架空のタスク管理アプリに「タスクの期限」を追加する作業)。新しいステアリングは `docs/procedures/templates/` のテンプレートから作成し、本ファイルは書き方の参考にする。steering lint は日付付きディレクトリだけを検査するため、本ディレクトリは検査対象外である。受け入れ条件のチェックは、検証で満たしたことを確認してから付ける(この例は検証の途中のため未チェック)。

## 概要

タスクに期限(日付)を設定できるようにし、期限切れのタスクを一覧で見分けられるようにする。

- **関連Issue**: https://github.com/your-org/your-repo/issues/1
- **使用ハーネス**: Claude Code
- **軽量パス**: 非適用

## パス判定

- [x] 1. 既存パターンの踏襲のみで、新しいアーキテクチャ要素・新規依存を導入しない
- [ ] 2. 変更対象が3ファイル以下(テスト除く)
- [x] 3. 対象文書(`AGENTS.md` とハーネスアダプタの規範記述・AGENTS.md プロダクト固有層が列挙する永続ドキュメント・`docs/procedures/` の手順書とテンプレート)の更新が不要
- [x] 4. データ形式・API契約の破壊的変更がない

**判定理由**:

- 基準1: 満たす。既存の属性追加と同じパターン(モデル・CLI・一覧画面)で、新規依存はない
- 基準2: 満たさない。変更対象は5ファイル(モデル、保存処理、CLI、一覧画面のテンプレート、スタイル)
- 基準3: 満たす。永続ドキュメントの方針は変わらない
- 基準4: 満たす。期限は省略可能な項目として追加し、既存データはそのまま読める

結論: **通常パス**(基準2を満たさない)。

## G3受け入れの要否判定

- **不要**。アプリのコードと画面だけを変え、ハーネスのアダプタ構成・権限・フック・ハーネス設定ファイルは変えない

## 背景

締め切りのあるタスクが、他のタスクに埋もれて見落とされている。

## ユースケースの軸

> ユーザーがタスクに期限を設定すると、期限切れのタスクが一覧で強調表示される。

## 実装対象の機能

### 1. 期限の設定
- CLI の `add` / `edit` に `--due YYYY-MM-DD` を追加する
- ユーザーは、タスクの作成時・編集時に期限を設定・解除できる

### 2. 期限切れの表示
- 一覧(CLI・画面)で、期限切れのタスクを強調表示する
- ユーザーは、期限切れのタスクをひと目で見分けられる

## 受け入れ条件

各条件に確認方法(自動テスト / エージェントの実機操作 / 人の確認)を付記する。

### 期限の設定
- [ ] `--due` で設定した期限が保存され、再読み込み後も保たれる(確認方法: 自動テスト)
- [ ] 不正な日付を指定するとエラーメッセージを表示し、保存しない(確認方法: 自動テスト + エージェントの実機操作(CLI を実際に起動))

### 期限切れの表示
- [ ] CLI の一覧で、期限切れのタスクに `!` が付く(確認方法: エージェントの実機操作)
- [ ] 画面の一覧で、期限切れのタスクが判別しやすい色で強調される(確認方法: エージェントの実機操作 + 人の確認(色の見やすさの判断))

## 成功指標

- 期限切れタスクの見落としに関する問い合わせがなくなる

## スコープ外

以下はこのフェーズでは実装しません:

- 期限前の通知
- 繰り返しタスク
